# Doomdolls — Bonecas com histórias
**Como usar o site Doomdolls**

A Doomdolls é uma loja virtual demonstrativa de bonecas colecionáveis. Para utilizar o site, siga os passos abaixo:

1. **Explore a página inicial:** veja os produtos em destaque e acesse as opções **Coleção**, **Novidades** e **Ofertas**.

2. **Encontre uma boneca:** utilize a pesquisa para procurar pelo nome ou explore o catálogo usando os filtros disponíveis.

3. **Confira os detalhes:** clique no produto para visualizar o preço, a descrição e as fotos. Selecione as miniaturas para trocar a imagem e utilize a lupa para observar os detalhes.

4. **Salve seus favoritos:** clique no coração do produto para adicioná-lo à área de favoritos e encontrá-lo novamente depois.

5. **Escolha como comprar:** clique em **Adicionar ao carrinho** para continuar escolhendo produtos ou em **Comprar agora** para seguir diretamente à finalização.

6. **Revise o carrinho:** confira os produtos, altere as quantidades ou remova itens. Informe um CEP para calcular o frete demonstrativo. Você também pode aplicar o cupom **DOOM10**, que oferece 10% de desconto nos produtos.

7. **Finalize a simulação:** preencha os dados solicitados com informações fictícias e escolha PIX, crédito ou débito. Marque a confirmação de que se trata de uma simulação e clique em **Simular compra**.

8. **Acompanhe o pedido:** na confirmação, clique em **Acompanhar pedido**. Também é possível consultar o histórico em **Perfil → Meus pedidos**.

9. **Personalize seu perfil:** em **Perfil → Meus dados**, altere a foto e preencha os dados de contato e endereço. Clique em **Salvar alterações** para guardar as informações.

**Observação:** o site é um projeto escolar. As compras, os pagamentos e o acompanhamento dos pedidos são simulados. Os dados ficam salvos apenas
